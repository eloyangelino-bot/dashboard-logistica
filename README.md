# Dashboard Logística

Aplicación Streamlit para analizar y comparar archivos de salidas logísticas.

## Archivos principales

- `app.py`
- `requirements.txt`
- `README.md`
- `.streamlit/config.toml`

## Uso en Streamlit

Main file path:

`app.py`

Para comparar dos cargas, subir:
1. archivo anterior
2. archivo actual

El sistema identifica automáticamente KEY/guía, fecha, supervisor, almacén, material, cantidad y estado cuando existen.
