# Dashboard Logística

Dashboard desarrollado con Streamlit para analizar archivos Excel de logística.

## Funciones

- Carga de Excel.
- Análisis de la carga actual.
- Comparación entre carga anterior y actual.
- Diferencia absoluta.
- Variación porcentual.
- Tendencia: aumenta, disminuye o sin cambio.
- Total de guías.
- Guías aprobadas.
- Guías pendientes.
- Unidades.
- Materiales.
- Encargados.
- Almacenes.
- Registros.

## Orden de comparación

Cuando se cargan dos archivos:

1. Primer archivo = carga anterior.
2. Segundo archivo = carga actual.

## Ejecución

Streamlit ejecuta el archivo:

`app.py`
