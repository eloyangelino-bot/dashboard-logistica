# Dashboard de Guías

Dashboard Streamlit centrado únicamente en:

- Guías / KEY únicas
- Estado de las guías
- Sede / almacén
- Encargado / supervisor
- Evolución mensual
- Matriz sede x mes
- Estado por sede
- Encargados por sede
- Comparación anterior vs actual con diferencia y porcentaje

No utiliza materiales ni cantidades de materiales.

## Streamlit

Main file path:
`app.py`

Con dos archivos:
1. Primer archivo = anterior
2. Segundo archivo = actual
